## 데이터 안전 섹션 (Play 콘솔 필수 입력)

### 수집하는 데이터

| 데이터 유형 | 수집 항목 | 수집 목적 | 필수/선택 | 공유 여부 |
|---|---|---|---|---|
| **개인정보 — 이메일** | Firebase Auth 이메일 (Google 로그인 시) | 계정 식별 | 선택 (게스트 가능) | Firebase (Google) |
| **개인정보 — 사용자 ID** | Firebase UID | 계정 식별 / 멀티플레이 매칭 | 필수 | Firebase (Google) |
| **개인정보 — 이름** | 닉네임 (사용자 입력) | 게임 내 표시 | 필수 | 같은 방 플레이어에게 표시 |

## 권한 정당화 (Play 콘솔)

`app.json` 의 `android.permissions` + Expo 자동 추가 권한:

| 권한 | 사용 이유 |
|---|---|
| `INTERNET` | 멀티플레이 게임 서버 (Railway) 통신 + Firebase 인증 |
| `VIBRATE` | 게임 진행 햅틱 피드백 (카드 제출, 폭탄 등) |
| `POST_NOTIFICATIONS` (Android 13+) | 친구 초대 / 매칭 / 게임 시작 푸시 알림 |
| `ACCESS_NETWORK_STATE` (Expo 자동) | 네트워크 연결 상태 감지 (재접속) |
| `RECEIVE_BOOT_COMPLETED` (expo-notifications 자동) | 부팅 후 예약된 알림 복원 |

위험 권한 (위치 / 연락처 / 카메라 / 마이크 / 저장소) 없음.
